# 圈出台灣｜Circle Taiwan v1.0.1

台灣本島網頁地理圈選遊戲。

**[▶ 線上直接玩](https://circle.hiyaowl.com/)**

## 玩法

- 圈出指定縣市、鄉鎮或村里，以真實行政邊界計算 IoU 吻合度。
- 單人不限時，在瀏覽器計分並查看逐題對照圖；多人支援 2～8 人以六碼房號邀請對戰。
- 初階有地形、道路與河川，高階只留海岸；桌面拖曳圈選，手機可切換圈選與移動。
