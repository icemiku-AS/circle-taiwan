# 圈出台灣｜Circle Taiwan v1.1.3

台灣本島網頁地理圈選遊戲。

**[▶ 線上直接玩](https://circle.hiyaowl.com/)**

## 玩法

- 圈出指定縣市、鄉鎮市區或村里，依圈選與正確範圍的吻合度計分。
- 景點挑戰支援全島／指定縣市、經典／全部題庫：全島經典 100 題、各縣自動精選 20 題，全部題庫共 5,554 筆本島官方紀錄。圈中代表點才得分，完整面積越小分數越高。
- 單人不限時，在瀏覽器計分並查看逐題對照圖；多人支援 2～8 人以六碼房號邀請對戰。
- 景點兩種難度都有行政區界線：全島顯示縣市界，縣市局顯示外框與鄉鎮界；初階另有地形、河川與道路，高階只留界線。行政區挑戰維持初階地形線索、高階海岸輪廓；題庫與線索難度獨立。
- v1.1.2 強化景點初階的縣市／鄉鎮邊界對比與線寬，讓界線在密集道路與河川上更清楚；高階與行政區模式維持原樣式。
- 景點揭曉顯示 Pin、未命中最近距離與完整面積；單人結算呈現命中率、平均得分，可下載含縣市外框與圖針的對照圖。

多人每題依名次與得分最高得 10 點；總積分相同時比平均得分，再相同則並列。揭曉後 10 秒自動換題，房主也可提前切換；結算後可點「返回大廳」同步房間狀態。完整計分公式與版本變更見 [CHANGELOG.md](CHANGELOG.md)。
