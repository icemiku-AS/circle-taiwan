# 圈出台灣｜Circle Taiwan v1.1.0

台灣本島網頁地理圈選遊戲。

**[▶ 線上直接玩](https://circle.hiyaowl.com/)**

## 玩法

- 圈出指定縣市、鄉鎮或村里，以真實行政邊界計算 IoU 吻合度。
- 景點挑戰支援全島／指定縣市、經典／全部題庫：全島「童年與畢旅回憶」經典 100 題、各縣自動精選 20 題，全部題庫共 5,554 筆本島官方紀錄。圈中代表點才得分，完整面積越小分數越高。
- 單人不限時，在瀏覽器計分並查看逐題對照圖；多人支援 2～8 人以六碼房號邀請對戰。
- 行政區初階有地形、道路與河川；景點全島初階有縣市界，縣市初階有外框與鄉鎮界。高階景點全島只留海岸，縣市局只留該縣市外框；題庫與線索難度獨立。
- 景點揭曉顯示 Pin、未命中最近距離與完整面積；單人結算呈現命中率、平均得分，可下載含縣市外框與圖針的對照圖。

多人每題依名次與得分最高得 10 點；總積分相同時比平均得分，再相同則並列。完整計分公式與版本變更見 [CHANGELOG.md](CHANGELOG.md)。v1.1.0 尚未部署，線上版本以正式發布為準。
