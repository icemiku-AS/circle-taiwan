# 圈出台灣｜Circle Taiwan v1.0.2

台灣本島網頁地理圈選遊戲。

**[▶ 線上直接玩](https://circle.hiyaowl.com/)**

## 玩法

- 圈出指定縣市、鄉鎮或村里，以真實行政邊界計算 IoU 吻合度。
- 景點挑戰收錄本島 19 縣市共 100 題：圈中代表點才得分，完整圈選面積越小分數越高；未命中顯示到圈選範圍的最近距離。
- 單人不限時，在瀏覽器計分並查看逐題對照圖；多人支援 2～8 人以六碼房號邀請對戰。
- 行政區初階有地形、道路與河川；景點初階提供縣市邊界。高階均只留海岸；桌面拖曳圈選，手機可切換圈選與移動。

多人每題依名次與得分最高得 10 點；總積分相同時比平均得分，再相同則並列。完整計分公式與版本變更見 [CHANGELOG.md](CHANGELOG.md)。景點功能目前列於未發布變更，線上版本以正式發布為準。
